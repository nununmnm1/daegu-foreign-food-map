# 대구 외국음식전문점 지도

대구광역시 일반음식점 인허가 데이터 중 업태구분이 `외국음식전문점(인도,태국등)`이고 영업상태가 `영업/정상`인 184곳을 지도에 표시합니다.

**지도 보기:** https://nununmnm1.github.io/daegu-foreign-food-map/

## 기능

- 점을 클릭하면 업소명, 도로명주소, 지번주소, 구·동, 인허가일자를 보여 줍니다.
- 같은 건물(같은 좌표)에 있는 업소는 점 하나로 묶고 팝업에 모두 표시합니다.
- 업소명·주소·동 이름 검색, 구·군 필터, 목록에서 업소를 누르면 해당 위치로 이동합니다.
- PC에서는 좌측 목록 + 우측 지도, 폭 860px 이하에서는 지도 위 · 목록 아래로 배치됩니다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 지도 페이지. 데이터와 구·군 경계가 파일 안에 들어 있어 별도 서버 없이 열립니다. |
| `data/daegu_foreign_food.json` | 업소 184곳의 이름, 주소, 인허가일자, WGS84 위경도 |

## 데이터 출처와 처리

- 업소: 대구광역시 일반음식점 인허가 데이터(2026년 10월 기준)
- 좌표: 원본 X/Y(EPSG:5174, 인허가 데이터 좌표계)를 `pyproj`로 WGS84(EPSG:4326)로 변환
- 구·군 경계: [southkorea-maps](https://github.com/southkorea/southkorea-maps) 통계청 2013년 시군구 경계(간소화). 2023년 대구로 편입된 군위군 포함
- 배경 지도: © [OpenStreetMap](https://www.openstreetmap.org/copyright) 기여자
- 지도 라이브러리: [Leaflet](https://leafletjs.com/) 1.9.4

업태 분류 기준의 목록이므로 외국인이 운영하는 식당 전체와는 다를 수 있습니다.
